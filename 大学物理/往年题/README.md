## 三、电磁学部分考点分布（依据 2008–2021 真题归纳）

### 3.1 静电场（第 1 章）

| 考点 | 出现频率 | 典型题 |
|---|---|---|
| 高斯定理求对称场强（球/柱/面） | 极高 | 带电球壳、无限长带电柱面、厚壁 $\rho=kx$ |
| 场强/电势叠加与积分 | 极高 | 带电直线、圆环、圆盘轴线上场强；带电球面 + 带电细线的力与电势能 |
| 电势与电势差（分段积分） | 高 | 球壳组电势、两球之间电势 |
| 电偶极子的场强/力矩/电势能 | 中 | 电偶极子在外场中的 $M=\vec{p}\times\vec{E}$、$W=-\vec{p}\cdot\vec{E}$ |
| 正方形/多电荷系统的场强与电势 | 中 | 四顶点电荷、三角形电荷 |

### 3.2 导体与电介质（第 2 章）

| 考点 | 出现频率 | 典型题 |
|---|---|---|
| 导体电荷分布（空腔、球壳、平行板） | 极高 | 球壳内外表面电荷、平行板四表面 |
| 点电荷 + 导体球（感应场强、电势、接地电量） | 极高 | 2020-2021 计算题 1 |
| 分层/部分填充介质的 $D$、$E$、$\sigma'$ | 极高 | 2020-2021 填空 1（两层介质球壳） |
| 电容器电容计算（平板/柱形/球形/串联） | 高 | 同轴电缆单位长度电容、半浸油铜球 |
| 电容式传感器与储能 | 中 | 液位计、除颤器、能量比 |

### 3.3 恒定磁场（第 3 章）

| 考点 | 出现频率 | 典型题 |
|---|---|---|
| 毕奥–萨伐尔积分（直导线、圆环、圆盘、薄片） | 极高 | 1/4 圆柱形薄片轴线场、旋转带电圆盘 |
| 安培环路定理（对称分布） | 极高 | 同轴电缆、螺绕环、无限大载流平面 |
| 洛伦兹力与圆周/螺旋运动 | 高 | 云室径迹、质子动能、回旋半径与周期 |
| 安培力与磁力矩 | 高 | 圆环张力、两线圈磁力矩比、无限大载流平面受力 |
| 磁介质（$H$、$\mu_r$、束缚电流） | 中 | 螺绕环充介质求 $B$、单芯电缆束缚电流 |

## 四、怎么用这些卷子（建议）

1. **先按章做**：学完一章，把该章相关的选择/填空一次扫完（不必整套做）；
2. **考前 3 天做整套**：至少完整做 2020-2021 A 卷 + 2015-2016 期末，限时 2 小时；
3. **只看计算题出题套路**：电磁学的计算题几乎固定在"高斯定理 + 环路定理 + 导体/介质"三类，配合 [第 1 章](../第1章_静电场/学习笔记_第1章_静电场.md)、[第 2 章](../第2章_导体与电介质/学习笔记_第2章_导体与电介质.md)、[第 3 章](../第3章_恒定磁场/学习笔记_第3章_恒定磁场.md) 的「考点分布」「往年题精选」两节使用；
4. 每做完一套，把错题的**考点**记到对应章节笔记的「易错点」表里。
