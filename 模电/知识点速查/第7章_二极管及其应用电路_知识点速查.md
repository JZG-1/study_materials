# 第7章 二极管及其应用电路
> 期末要点速查 · 电路与模拟电子学 · 模电第一站

> ★ 一句话：**单向导电 + 一个模型选择** —— 恒压降模型打天下。

## 本章考点清单
- 半导体与 PN 结（多子/少子、正偏反偏）
- 二极管的伏安特性：$U_{on}$、0.7 V、反向饱和电流、击穿
- 四种模型：理想、恒压降、折线、**小信号**
- **判断二极管通断**（大题第一步）
- 应用电路：整流、限幅、钳位、峰值检测
- 齐纳（稳压）二极管与稳压电路

## 1. 半导体基础
- 半导体：导电能力介于导体与绝缘体之间，**热敏、光敏、掺杂后导电能力大增**
- 本征半导体：自由电子与空穴**成对**产生、成对消失，统称载流子
- **N 型**（掺五价元素如磷）：多子＝自由电子，少子＝空穴
- **P 型**（掺三价元素如硼）：多子＝空穴，少子＝电子
- **多子浓度由掺杂浓度决定，与温度无关**；少子浓度低且随温度变化明显（影响器件性能）
- PN 结：P 区与 N 区交界处的空间电荷区（耗尽层），存在内电场

## 2. 二极管的伏安特性
| 状态 | 条件 | 表现 |
|---|---|---|
| 正偏导通 | $u_D>U_{on}$ | 等效小电阻，硅管导通压降约 **0.7 V**（死区 0.5 V，锗 0.2/0.3 V） |
| 反偏截止 | $u_D<0$ | 反向饱和电流 $I_S$ 很小且基本不随电压变 |
| 反向击穿 | $u_D<-U_{BR}$ | 反向电流急剧增大（稳压管就工作在这里） |

- 结论：**单向导电性**——正偏低阻大电流，反偏高阻小电流
- 温度每升高 10 ℃，$I_S$ 约增大一倍；温度每升 1 ℃，$u_D$ 约减小 2~2.5 mV

## 3. 二极管的四种模型
| 模型 | 正向等效 | 适用场合 |
|---|---|---|
| 理想模型 | 短路（0 V） | 大信号、精度要求低 |
| 恒压降模型 | 恒压源 $U_D=0.7$ V | **最常用**（大信号/直流） |
| 折线模型 | $U_{on}$ 串联 $r_D$ | 需考虑斜率时 |
| 小信号模型 | 电阻 $r_d=U_T/I_{DQ}$ | 直流偏置 + 小信号 |

> 大信号模型用于直流与大幅信号；小信号模型只用于**交流小信号**（必须先在 Q 点求 $r_d$）。

## 4. 判断二极管通断（必考步骤）
**电压法（开路电压法）**：
1. 先假设二极管断开
2. 求两端开路电压 $u_{AK}$（阳极对阴极）
3. 若 $u_{AK}>U_{on}$（硅 0.5~0.7 V）⇒ **导通**；否则截止
4. 导通后用恒压降模型替换（$u_D=0.7$ V）重新计算，**核对导通电流是否 > 0**

**多个二极管**：分别求开路电压，**开路电压大的优先导通**；它导通后重新判断其余管（可能被"钳"成截止）

> 检查一致性：若算出导通管电流为负，说明假设错误，须重判。

## 5. 应用电路（画波形题）
| 电路 | 功能 | 要点 |
|---|---|---|
| 半波整流 | 只留正半周 | 输出有直流分量 |
| 全波/桥式整流 | 两个半周都利用 | 输出为全波脉动 $u_o=\vert u_s\vert$ |
| 限幅（削波） | 输出幅度受限 | 与电压源 $U$ 串联：$u_o\le U$ 或 $\ge U$ |
| 钳位 | 波形整体上/下移，形状不变 | 必须有电容，且**从二极管导通那半周开始分析** |
| 峰值检测 | 记住输入峰值 | 电容 + 二极管 |

**钳位电路分析口诀**：二极管导通 → 电容充电到 $U_m$；二极管截止 → 电容无放电回路，两端电压保持不变（相当于恒压源）；输出 = 输入 + 电容电压。

## 6. 齐纳（稳压）二极管
- 工作在**反向击穿区**：电流大范围变化时电压几乎不变 → 稳压
- 参数：稳定电压 $U_Z$、$I_{Z\min}$（拐点 $I_{ZK}$，小于它不能稳压）、$I_{Z\max}$（受功耗限制）、动态电阻 $r_Z$
- 模型：理想（$U_Z$ 恒压源）／实际（$U_Z$ 串联 $r_Z$）
- 稳压条件：限流电阻上的电流 $I_R=I_Z+I_L$，必须满足 $I_{Z\min}\le I_Z\le I_{Z\max}$

## 典型例题：多二极管电路求输出电位
**题**：硅二极管 $D_1$、$D_2$ 共阴极接在 $O$ 点，$O$ 点经 $R=1$ kΩ 接地；$D_1$ 阳极接 $+3$ V，$D_2$ 阳极接 $+1$ V。用恒压降模型（$U_D=0.7$ V），求 $u_O$ 与 $R$ 中的电流。

**解**：
1. **比较阳极电位**：$3\ \text{V}>1\ \text{V}$，故 $D_1$ **优先导通**
2. $D_1$ 导通后把 $O$ 点"拉"到：
$$
u_O=3-0.7=2.3\ \text{V}
$$
3. **核对 $D_2$**：$u_{AK2}=1-2.3=-1.3\ \text{V}<0.7\ \text{V}$ ⇒ $D_2$ **截止**
4. **电流**：$i=\dfrac{u_O}{R}=\dfrac{2.3}{1\text{k}}=2.3$ mA $>0$ ✓（与"$D_1$ 导通"一致）

> 思路：**阳极电位高的优先导通**；它导通后把公共点电位拉过去，再检查另一只管是否还能导通（若算出导通电流为负，说明假设错误，需重判）。

> 小结：两只二极管"抢"同一个输出点时，结果只由**电位最高的那一路**决定（相当于取最大值再减 0.7 V）。

## 易错点速记
1. 恒压降模型只在**正偏导通**时用；截止时按开路处理
2. 判断通断必须"先假设、后核对电流方向"
3. 钳位电路电容上的电压极性容易画反——从导通半周定
4. 稳压管正常工作时**反向**接（阴极接高电位）；正偏时它只是个普通二极管
5. N 型半导体多子是电子，P 型多子是空穴（选择/填空高频）
