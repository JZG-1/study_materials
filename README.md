## 在手机上看

1. 安装 GitHub 手机 App，或直接用浏览器打开 `github.com/JZG-1/study_materials`
2. 私有仓库需先登录同一账号
3. 点开任意 `.md` 文件即可阅读

> **手机 App 的一个已知缺陷**：App 的 Markdown 渲染器不显示相对路径的图片（私有仓库 + 中文目录更容易触发），文字正常、图片空白。
>
> 本仓库的图片已改为 **raw 绝对地址**，仓库公开后 App 内应能正常显示。若仍空白，可用手机浏览器打开同一页面，或滑到每篇笔记末尾的「图片清单」点链接打开原图。
